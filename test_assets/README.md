# Test corpus

Everything here except this README is generated by [`tool/gen_corpus.sh`](../tool/gen_corpus.sh). Don't edit the files by hand. Every clip is drawn procedurally by the script, so the corpus contains no third-party or Telegram media.

```sh
tool/gen_corpus.sh           # regenerate (idempotent)
tool/gen_corpus.sh --check   # validate manifest.json and refs against the files
```

The generator needs `ffmpeg`/`ffprobe` built with libvpx and libopus, `img2webp` and `gif2webp` (libwebp), `gifsicle`, `jq`, `gzip` and `openssl`. On macOS: `brew install ffmpeg webp gifsicle jq`.

The committed corpus was generated with ffmpeg 9.0.2 (libvpx 1.17.0, opus 1.6.1), libwebp 1.6.0 and gifsicle 1.98. Other versions produce different bytes, so commit a regeneration only when you mean to change the corpus. `fvm flutter test test/corpus_manifest_test.dart` runs the structural checks in CI without ffmpeg.

| File | Size | Frames | What it covers |
|---|---|---|---|
| `vp9_alpha_512.webm` | 512×512 | 90 @ 30 fps | VP9 + alpha (BlockAdditional), keyframes at 0 and 45 |
| `vp9_opaque_256.webm` | 256×256 | 60 @ 30 fps | No alpha track. Two-pass alt-ref, so 5 hidden frames ride in superframes |
| `vp8_alpha_256.webm` | 256×256 | 60 @ 30 fps | VP8 + alpha, keyframes at 0 and 30 |
| `vp9_alpha_vfr.webm` | 192×192 | 32 | Frame durations cycle 40/80/120/200 ms |
| `vp9_odd_301x199.webm` | 301×199 | 30 @ 30 fps | Odd width and height (chroma rounds up) |
| `vp9_single_frame.webm` | 256×256 | 1 | One frame only |
| `vp9_with_audio.webm` | 128×128 | 30 @ 30 fps | Has an Opus audio track to skip |
| `vp9_2048.webm` | 2048×2048 | 2 | Over the 1024 px limit (`expect: limit_exceeded`) |
| `truncated.webm` | 512×512 | 60 complete | `vp9_alpha_512.webm` cut inside frame 60, mid-cluster (`expect: truncated`) |
| `garbage.bin` | – | – | 4 KiB of AES-CTR keystream with no container magic (`expect: invalid`) |
| `anim.webp` | 128×128 | 16 | Animated WebP: frames 0–7 lossless, 8–15 lossy + ALPH, mixed durations |
| `anim_disposal.gif` | 96×96 | 6 | Every GIF disposal method (0–3), sub-rectangles, transparency, one interlaced frame |

The colour content is smooth RGB gradients. The alpha content is a soft-edged disc that orbits the centre plus an alpha ramp along the bottom, so every alpha value from 0 to 255 appears.

## `manifest.json`

One entry per file, in the order above:

| Field | Meaning |
|---|---|
| `name`, `bytes`, `sha256` | The file itself |
| `kind` | `webm`, `webp`, `gif` or `unknown` |
| `expect` | `ok`, `limit_exceeded`, `truncated` or `invalid` |
| `codec` | `vp9`, `vp8`, `webp` or `gif` |
| `width`, `height` | Canvas size in pixels |
| `alpha` | WebM: the track has `AlphaMode = 1` |
| `has_audio` | The file has an audio track |
| `frame_count` | Displayed frames. For `truncated.webm`, frames that are complete before the cut |
| `pts_ms` | Presentation time of each frame |
| `durations_ms` | WebM: time until the next frame starts. The last frame uses the container's default duration. GIF/WebP: the stored frame delay |
| `keyframes` | WebM keyframe indices |
| `ref_frames` | Frame indices that have a reference frame |
| `truncated_from` | The intact source of a truncated file |

`garbage.bin` has only the first five fields plus an empty `ref_frames`.

## Reference frames

`ref/<name>/<frame>.rgba.gz`, where `<frame>` is the zero-padded 3-digit index. Each one is a gzip of `width × height × 4` bytes of **premultiplied** RGBA8888, rows top to bottom, with no padding. Premultiplying is exact: `round(c × a / 255)`.

- **VP8/VP9**: decoded with libvpx through ffmpeg, so the alpha track is honoured. YUV is converted as BT.601 limited range, which is how the clips are tagged and what libyuv's `I420AlphaToABGR` does. Chroma upsampling differs slightly from libyuv, so compare with a PSNR threshold, not bit-exactly.
- **WebP**: decoded by ffmpeg's `webp_anim` decoder. The lossless frames match the source images exactly.
- **GIF**: composited by `gif2webp` (giflib) and decoded losslessly. These are browser semantics: the canvas starts transparent, and "restore to background" clears the rectangle to transparent rather than to the palette background colour.

WebM clips have reference frames for the first, middle and last frame, plus each keyframe and the frame before it, where inter-frame drift peaks. GIF and WebP have every frame. Clips that are expected to fail have none. [ADR 0001](../docs/decisions/0001-sampled-reference-frames.md) explains why the frames are sampled and gzipped.
