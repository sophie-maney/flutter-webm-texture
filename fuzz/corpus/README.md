# Fuzz seed corpora

Seed directories for the fuzz targets. `tool/fuzz.sh` passes them after a
scratch directory under `build/fuzz/corpus/`, because libFuzzer writes new
inputs into the first corpus directory.

| Target | Seeds |
|---|---|
| `fuzz_sniff` | `test_assets/` |
| `fuzz_probe` | `test_assets/`, `fuzz/corpus/webm/` |
| `fuzz_webm` | `fuzz/corpus/webm/` (+ `fuzz/webm.dict`) |

When a run finds a bug, fix it and add the reproducer from
`build/fuzz/artifacts/<target>/` to the target's seed directory as a
regression input, named after what it triggers.

## `webm/` (`fuzz_webm`)

- Every `*.webm` in `test_assets/`, copied unchanged (generated by
  `tool/gen_corpus.sh`).
- `*_live.webm`: the same clips remuxed by ffmpeg's live WebM mode, which
  writes an unknown-size Segment (Clusters keep their sizes):

  ```sh
  for f in vp9_with_audio vp8_alpha_256 vp9_alpha_vfr; do
    ffmpeg -v error -i test_assets/$f.webm -map 0 -c copy -f webm -live 1 - \
      > fuzz/corpus/webm/${f}_live.webm
  done
  ```
- `*_unknown.webm`: unknown-size Segment **and** Clusters, as MediaRecorder
  writes them (spike A, pitfall 12):

  ```sh
  for f in vp9_with_audio vp9_alpha_vfr; do
    python3 -I tool/unknown_size_webm.py test_assets/$f.webm \
      fuzz/corpus/webm/${f}_unknown.webm
  done
  ```

`fuzz/webm.dict` lists the EBML IDs and strings the demuxer looks for.
