# Fuzz seed corpora

Seed directories for the fuzz targets. `tool/fuzz.sh` passes them after a
scratch directory under `build/fuzz/corpus/`, because libFuzzer writes new
inputs into the first corpus directory.

| Target | Seeds |
|---|---|
| `fuzz_sniff` | `test_assets/` |
| `fuzz_probe` | `test_assets/`, `fuzz/corpus/webm/`, `fuzz/corpus/webp/`, `fuzz/corpus/gif/` |
| `fuzz_webm` | `fuzz/corpus/webm/` (+ `fuzz/webm.dict`) |
| `fuzz_webp` | `test_assets/`, `fuzz/corpus/webp/` (+ `fuzz/webp.dict`) |
| `fuzz_gif` | `test_assets/`, `fuzz/corpus/gif/` (+ `fuzz/gif.dict`) |
| `fuzz_wsc` | `fuzz/corpus/wsc/` (+ `fuzz/wsc.dict`) |

When a run finds a bug, fix it and add the reproducer from
`build/fuzz/artifacts/<target>/` to the target's seed directory as a
regression input, named after what it triggers.

## `webm/` (`fuzz_webm`)

- Every `*.webm` in `test_assets/`, copied unchanged (generated by
  `tool/gen_corpus.sh`).
- `*_live.webm`: the same clips remuxed by ffmpeg's live WebM mode, which
  writes an unknown-size Segment (Clusters keep their sizes):

  ```sh
  for f in vp9_with_audio vp8_alpha_256 vp9_alpha_vfr; do
    ffmpeg -v error -i test_assets/$f.webm -map 0 -c copy -f webm -live 1 - \
      > fuzz/corpus/webm/${f}_live.webm
  done
  ```
- `*_unknown.webm`: unknown-size Segment **and** Clusters, as MediaRecorder
  writes them (spike A, pitfall 12):

  ```sh
  for f in vp9_with_audio vp9_alpha_vfr; do
    python3 -I tool/unknown_size_webm.py test_assets/$f.webm \
      fuzz/corpus/webm/${f}_unknown.webm
  done
  ```

`fuzz/webm.dict` lists the EBML IDs and strings the demuxer looks for.

## `wsc/` (`fuzz_wsc`)

Small, valid frame cache files (`docs/cache-format.md`) of corpus clips,
within the fuzzer's limits (256 px, 64 frames). Regenerate them from a fuzz
build when the format or the corpus changes:

```sh
cmake --build build/fuzz --target wsc_seeds
build/fuzz/wsc_seeds test_assets fuzz/corpus/wsc
```

`fuzz/wsc.dict` lists the magic and common header values.

## `webp/` (`fuzz_webp`, `fuzz_probe`)

Small hand-made WebPs, also read by `native_test/webp_test.cc`. The animated
corpus file `test_assets/anim.webp` is the main seed and comes from
`test_assets/`.

- `still_lossless_alpha.webp`, `still_lossy.webp`: non-animated files (a
  VP8L with alpha, a lossy VP8), made with `cwebp -lossless -exact` and
  `cwebp -q 70` from a 12x8 and a 16x16 gradient.
- `anim_zero_duration.webp`: two lossless 12x8 frames muxed with
  `webpmux -frame a.webp +0+0+0+0-b -frame b.webp +40+0+0+1+b`, so the first
  frame has duration 0 (the 100 ms policy, ADR 0022).

## `gif/` (`fuzz_gif`, `fuzz_probe`)

Small GIFs crafted with the test writer `native_test/gif_writer.h`, also
usable as hand inputs. The animated corpus file `test_assets/anim_disposal.gif`
is the main seed and comes from `test_assets/`. Regenerate them from a fuzz
build when the writer changes:

```sh
cmake --build build/fuzz --target gif_seeds
build/fuzz/gif_seeds fuzz/corpus/gif
```

- `interlaced_disposals.gif`: an interlaced first frame, then "background" and
  "previous" disposals.
- `local_palette_transparent.gif`: a local colour map and a transparency index.
- `oversized_rect.gif`: a rect that sticks out of the canvas and one wholly
  outside it (clipping).
- `zero_screen.gif`: a zero-size logical screen (taken from the first frame).
- `zero_delay.gif`: delays of 0, 1 and 2 cs (the 100 ms policy, ADR 0023).
- `previous_first.gif`: "restore to previous" on the first frame.
- `short_lzw_no_trailer.gif`: an LZW stream that ends early (a decode error)
  and no trailer (a truncated file).
- `huge_rect_no_palette.gif`: a 65535 x 65535 rect and no colour map.

`fuzz/gif.dict` lists the block introducers, extension labels and header
bytes the demuxer looks for.
